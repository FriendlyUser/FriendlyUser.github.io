KAndroid Kotlin extensions for Android, and what replaces them today

May 3, 2023Mobile & Android
  • #kotlin
  • #android

KAndroid is unmaintained

KAndroid’s last release, 0.8.8, came out in August 2018. It’s built against the old Android Support Library rather than AndroidX, so an AndroidX app needs Jetifier enabled to use it. Its own find() helper is marked deprecated in favour of findViewById(). For new code, use Android KTX, View Binding and Kotlin coroutines instead. The equivalents are listed at the end.

KAndroid is a small Apache-2.0 library by Paweł Gajda. It adds Kotlin extension functions for repetitive Android code: text watchers, toasts, intents, threading and logging. It doesn’t add new features. Each helper is a thin wrapper over the platform API it replaces.

Logging

Section titled “Logging”

The log functions are extensions on Any and use the caller’s class name as the tag:

The lambda forms (d { }, v { }, i { }) only build the message if Log.isLoggable(tag, level) returns true. By default only INFO and above pass that check, so d { } prints nothing unless you raise the level with adb shell setprop log.tag.<ClassName> DEBUG. The string overloads always log.
