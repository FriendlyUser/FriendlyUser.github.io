LaTeX beyond the basics: CVs, invoices, theses and books

Dec 14, 2024LaTeX
  • #latex

Once you can write an article, most “advanced” LaTeX work is choosing the right document class or package for the job and learning its few commands. This post covers the usual choices for a CV, an invoice, a thesis or a book, with examples you can compile.

One distinction trips people up: a class is loaded with \documentclass{...} and defines the whole document (moderncv, europecv, memoir, scrbook, beamer). A package is loaded with \usepackage{...} on top of a class (invoice, biblatex, siunitx). Writing \usepackage{moderncv} won’t work, because moderncv is a class.

Packages worth knowing

Section titled “Packages worth knowing”

These come up in almost every larger document:

  • geometry: page size and margins, e.g. \usepackage[margin=1in]{geometry}.
  • hyperref: clickable cross-references, URLs (\url, \href) and PDF bookmarks. Load it near the end of the preamble.
  • amsmath: align, cases, matrices and other multi-line maths.
  • siunitx: numbers and units with consistent spacing (\qty{25}{\celsius}).
  • biblatex (with the biber backend) or natbib (with BibTeX): citations and bibliographies.
  • glossaries: glossaries and acronym lists.
  • TikZ (\usepackage{tikz}): diagrams drawn in LaTeX code.
  • beamer (a class): slides.
  • minted or listings: source code listings. minted highlights with Python’s Pygments, so it needs Python at compile time; listings is pure LaTeX.

europecv

Section titled “europecv”

europecv is an unofficial class for the Europass CV layout. The CV goes inside a europecv environment, personal details are set in the preamble and printed with \ecvpersonalinfo, and each row is an \ecvitem{left column}{right column}. The class manual marks \ecvsection as deprecated; use a normal \section instead.

Commands such as \ecvworkexperience or \ecvskills don’t exist. Check texdoc europecv for the full list.

Templates

Section titled “Templates”

If you’d rather start from a finished design than a class, Awesome CV and AltaCV are popular templates on GitHub and Overleaf. Awesome CV uses fontspec, so it needs XeLaTeX or LuaLaTeX rather than pdfLaTeX.

Invoices and letters

Section titled “Invoices and letters”

The invoice package gives you an invoice environment that does the arithmetic. It takes two arguments: the currency name and the VAT rate as a plain number (0 hides the VAT lines). Inside it you open a project with \ProjectTitle, list fees with \Fee{description}{rate}{count}, then expenses with \EBC{description}{amount}. Fees must come before expenses.

Subtotals and the total are calculated for you. There’s no \Total or \tax command. \Discount{description}{amount} deducts a down payment. The manual recommends ending each \ProjectTitle{...} line with % so the first column lines up. The package doesn’t handle logos, addresses or bank details. Put the invoice inside a letter class for those. With KOMA-Script’s old scrlettr class the environment is renamed to invoiceenv. CTAN also lists invoice2, a separate LaTeX3-based package.

For the letter itself, use the standard letter class or KOMA-Script’s scrlttr2 class, which handles sender/recipient fields, window envelopes and closings.

Books

Section titled “Books”

The standard book class gives you chapters, front/back matter and two-sided layout. For more control, two classes do most of the work:

  • memoir: a book class that includes many packages’ features (page layout, headers, chapter styles, epigraphs).
  • scrbook: KOMA-Script’s book class, with its own font and layout interface.

Finding documentation

Section titled “Finding documentation”
  • texdoc <name> (e.g. texdoc moderncv) opens a package’s manual from your TeX Live install. The manuals are the most reliable reference, and most include complete examples.
  • CTAN: the central archive of TeX packages. Each package page links to its manual and shows the current version.
  • TeX Stack Exchange: searchable answers to most error messages.
  • Overleaf documentation and the LaTeX Wikibook: readable introductions to most of the topics above.
  • The LaTeX Companion (3rd edition, Mittelbach and Fischer): the book-length reference for packages.
