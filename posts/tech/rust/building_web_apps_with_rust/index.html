Building a web app in Rust with Actix Web (routing, logging, Postgres and templates)

Apr 29, 2024Rust
  • #rust
  • #bash

Actix Web is an async web framework for Rust. You register handler functions on routes; handlers take typed extractors (path segments, JSON bodies, shared state) as arguments and return anything that implements Responder. Since version 4 it runs on the Tokio-based actix-rt runtime and no longer depends on the Actix actor framework.

This post builds up a small app: a hello-world route, a path parameter, request logging, a Postgres insert with sqlx, and an HTML page rendered with Tera plus static files. The examples were checked against actix-web 4.19.0.

Section titled “Database access with sqlx”

sqlx is an async SQL toolkit. The connection pool is shared with handlers through web::Data, which wraps it in an Arc. The dependencies (checked against sqlx 0.9.0):

The handler returns 201 Created with the new UUID as JSON. Notes:

  • web::Data::new is created once, outside the HttpServer::new closure, and cloned into each worker. Creating it inside the closure would give every worker its own pool.
  • The id is generated in Rust, so the table needs no DEFAULT. If you want Postgres to generate it, gen_random_uuid() is built in from Postgres 13; uuid_generate_v4() needs the uuid-ossp extension.
  • The sqlx::query! macro checks SQL against a real database at compile time, which means DATABASE_URL must be set (or offline data prepared with sqlx-cli) when you build. The plain sqlx::query used here is checked only at runtime.
  • In a real app, create tables with migrations (sqlx migrate) rather than at startup.

Gotchas

Section titled “Gotchas”
  • App::data() from older tutorials was removed in Actix Web 4; use .app_data(web::Data::new(...)). A handler asking for web::Data<T> that was never registered gets a 500 error at request time, not a compile error.
  • The templates/**/* glob and the static directory are relative to the working directory, so run the binary from the project root (or build absolute paths with env!("CARGO_MANIFEST_DIR")).
  • #[get], #[post] and friends must be imported (use actix_web::{get, post}) and the handlers registered with .service(), not .route().
