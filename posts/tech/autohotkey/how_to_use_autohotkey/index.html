AutoHotkey v2 basics: hotkeys, hotstrings, remaps and window automation

Sep 14, 2024C++ & systems
  • #autohotkey

AutoHotkey is a free, open-source scripting language for Windows. You use it to bind hotkeys, remap keys, expand abbreviations as you type, and automate clicks, keystrokes and window management.

Note

All examples below use AutoHotkey v2 syntax, the current major version. v2 is not backwards compatible: v1.1 scripts (MsgBox, Hello, Run, notepad.exe, %var%) won’t run under v2, and many older tutorials and forum posts use v1 syntax.

Installing and running scripts

Section titled “Installing and running scripts”

Download the installer from autohotkey.com and run it. Scripts are plain-text .ahk files; double-click one to run it. While a script is running it shows a green “H” icon in the system tray, where you can reload, pause or exit it.

To run a script when you log in, put a shortcut to it in your Startup folder (press Win+R and enter shell:startup).

Targeting specific apps or windows

Section titled “Targeting specific apps or windows”

Most window functions take a WinTitle argument. It can be a window title (or the start of one), or criteria such as ahk_exe notepad.exe, ahk_class Notepad or ahk_id. "A" means the active window. See WinTitle.

To find a window’s title, class or process name, use Window Spy. Open it from the tray menu of any running script, from the Start menu, or from the AutoHotkey Dash.

Sending keystrokes

Section titled “Sending keystrokes”

Send types into the active window. Modifier symbols work the same as in hotkeys, and special keys go in braces:

There’s no inline delay syntax; use SetKeyDelay (which applies to SendEvent mode) if a target app drops keystrokes. See Send.

ControlSend sends keys to a control in a window that doesn’t need to be active:

Some apps ignore ControlSend. Modern UI frameworks often don’t expose standard controls like Edit1 (the Windows 11 Notepad is one of them). In that case, activate the window with WinActivate, use Send, then switch back.

Recording macros with Pulover’s Macro Creator

Section titled “Recording macros with Pulover’s Macro Creator”

If you’d rather record actions than write them, Pulover’s Macro Creator is a recorder and editor built on AutoHotkey. Be aware that its last release (5.4.1) was in 2021.

  1. Start Pulover’s Macro Creator.
  2. Press the record hotkey (F9 by default) and perform your mouse and keyboard actions.
  3. Press the record hotkey again to stop.
  4. Press the playback hotkey (F3 by default) to replay.

The Options menu controls recording mode, delays and coordinate mode, and recorded macros can be edited, saved and exported. See the help page.
